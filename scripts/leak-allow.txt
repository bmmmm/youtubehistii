# real watch history — but some of those subjects are generic words the code

# naming one says nothing about anybody. Blocking those would make the gate
# fire on honest pushes, and a gate that cries wolf teaches --no-verify.

# here would identify the person watching, it does not belong in this file —
# rename the fixture instead.

# internal/rules/youtube.go), so they do not need to be listed here.
